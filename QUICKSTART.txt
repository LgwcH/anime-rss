AniRSS 0.1.5 快速开始
=====================

当前 0.1.5 先提供源码包与 Python wheel。Windows x86_64 便携包只有在取得可信 Authenticode
签名并通过安全产品复核后才会发布；不要继续使用或恢复被 Defender 隔离的 0.1.4 EXE。

一、校验与解压
--------------

1. 若正式发布目录中提供了已签名 Windows ZIP，将 ZIP 与 SHA256SUMS.txt 放在同一目录；仅有
   源码包/wheel 时请按发布说明从可信 Python 环境安装，不要自行寻找第三方重打包 EXE。
2. 在 PowerShell 中计算 ZIP 的 SHA-256：

   Get-FileHash .\AniRSS-0.1.5-windows-x86_64-with-bt.zip -Algorithm SHA256

3. 将结果与 SHA256SUMS.txt 中同名文件的一行比较；不一致时不要运行该文件。
4. 把 ZIP 完整解压到固定目录，例如 D:\Apps\AniRSS。

请保留 AniRSS.exe 和 _internal 文件夹的相对位置。AniRSS.exe 不是单文件程序，只复制或移动
AniRSS.exe 会导致程序无法启动。不要直接在 ZIP 压缩包预览窗口中运行程序。

二、首次设置
------------

1. 双击 AniRSS.exe。
2. 打开“设置”，选择默认下载目录，并按需设置并发下载数、RSS 轮询间隔、主题、系统托盘、
   桌面通知和当前用户级开机自启动。
3. 设置中的代理只用于 RSS 和 HTTP 请求，不会代理 BT 的 Tracker、DHT、PEX 或节点连接。
4. 点击“保存设置”。修改并发下载数后，重启 AniRSS 才能保证新并发数完整生效。

三、添加订阅
------------

1. 打开“订阅”，点击“新增订阅”。
2. 填写番剧名称和 HTTP/HTTPS RSS 或 Atom 地址。
3. 保存目录留空时，AniRSS 会在默认下载目录下自动创建安全化的番剧子文件夹；也可以为该
   订阅选择一个专用的绝对目录。
4. 按需填写“必须包含”“排除关键词”和“集数正则”，并开启“自动下载”。
5. 建议保持“首次刷新时也下载订阅中已有的条目”关闭，然后保存订阅。

首次成功刷新默认只把订阅中当时已有的条目记录为本地基线，不会下载这些历史条目。之后新增、
符合过滤规则且带有可识别下载链接的条目才会自动入队。只有确实需要下载源中全部已有条目时，
才在首次刷新前显式打开该选项。

保存后点击番剧名称可进入订阅详情；可以刷新当前订阅，查看和搜索已记录条目，并对带有下载地址
的内容逐条点击“下载”。自主下载只处理选中的条目，即使“自动下载”关闭或条目未匹配关键词也
可以使用，但不会生成重复任务。任务会显示在“下载”页，可暂停、继续、移除或打开保存目录。

四、BT 与做种说明
----------------

本 Windows 包已包含 BT/磁力链接能力。默认设置是下载完成后不继续做种；如确有授权，可在设置
中开启完成后继续做种，并指定做种分钟数。

“下载完成后不做种”不等于“从不上传”。BitTorrent 在下载阶段仍可能向其他节点上传数据，并会
向 BT 网络暴露你的 IP 地址。若内容许可或网络政策禁止再分发，请不要使用种子或磁力链接，改用
获得授权的 HTTP 下载方式。

五、数据与隐私
--------------

Windows 默认应用数据目录：

  %LOCALAPPDATA%\AniRSS

其中 anirss.db 保存订阅、已见条目、任务和设置，logs\anirss.log 保存本地轮转日志。数据库可能
包含完整订阅 URL、下载 URL、标题、Token、passkey 或代理信息，且不做应用层加密。不要公开
数据库或原始日志；反馈问题前请先移除私人地址、凭据、标题和本地用户名。

媒体文件保存在“设置”中的默认下载目录或订阅专用目录。删除 AniRSS 程序目录不会自动删除应用
数据或已经下载的媒体；卸载前请先关闭开机自启动并完全退出系统托盘中的 AniRSS。

六、重要限制与合法使用
----------------------

AniRSS 0.1.5 是 Alpha 版本，不提供 OPML 导入/导出、保存前订阅测试、独立人工确认
候选队列、HTTP 自动重试、BT 分享率停止、BT/SOCKS 代理、云同步或远程控制，也不会自动解压、
安装或执行下载内容。

AniRSS 只是通用 RSS 与下载工具，不提供内容源，也不绕过 DRM、付费墙或访问控制。只能订阅、
下载和分享自己有权访问的内容，并应遵守内容许可、服务条款、网络政策和当地法律。

更多变更和限制请阅读 RELEASE_NOTES-0.1.5.md。
